## Requisitos Não Funcionais (RNF)

| ID | Categoria | Descrição |
| --- | --- | --- |
| RNF-01 | Usabilidade | Interface simples e intuitiva, com navegação linear e botões grandes |
| RNF-02 | Usabilidade | WebApp responsivo funcionando em celular, tablet e desktop |
| RNF-03 | Desempenho | O WebApp deve carregar em até 3 segundos em conexão 3G |
| RNF-04 | Desempenho | Suportar ao menos 500 usuários simultâneos na versão inicial |
| RNF-05 | Segurança | Todas as comunicações devem utilizar HTTPS |
| RNF-06 | Segurança | Senhas criptografadas (SHA-256 ou superior) |
| RNF-07 | Segurança | Dados pessoais protegidos conforme LGPD |
| RNF-08 | Confiabilidade | Disponibilidade mínima de 99% mensal |
| RNF-09 | Confiabilidade | Sistema deve registrar falhas em log para depuração |
| RNF-10 | Infraestrutura | WebApp deve rodar em qualquer navegador moderno (Chrome, Firefox, Edge, Safari) |
| RNF-11 | Infraestrutura | Hospedagem em ambiente cloud com autoescalonamento básico |
| RNF-12 | Padrões | Código versionado com Git |
| RNF-13 | Padrões | API seguindo padrão REST |
| RNF-14 | Acessibilidade | Seguir diretrizes WCAG 2.1 nível AA |
| RNF-15 | Integridade | Cada perfil (cidadão, gestor, admin) tem acesso restrito às suas informações |

## Regras de Negócio (RNG)

| ID | Categoria | Descrição |
| --- | --- | --- |
| RNG-01 | Identificação | Todo usuário deve se autenticar com e-mail e senha |
| RNG-02 | Identificação | A senha deve conter de 6 a 12 caracteres alfanuméricos |
| RNG-03 | Identificação | Cada perfil tem acesso individual conforme seu nível de permissão |
| RNG-04 | Denúncia | A denúncia deve conter obrigatoriamente: foto, localização GPS e categoria |
| RNG-05 | Denúncia | Uma denúncia só pode ser resolvida pelo órgão público competente |
| RNG-06 | Denúncia | O status da denúncia segue o fluxo: registrada → em análise → em execução → resolvida |
| RNG-07 | Denúncia | O cidadão pode registrar no máximo 10 denúncias por dia |
| RNG-08 | Transparência | O mapa público exibe apenas denúncias com status “registrada” ou “em andamento” |
| RNG-09 | Gestão | O dashboard do gestor só exibe dados da sua região/município |
| RNG-10 | Gestão | Relatórios mensais devem ser gerados automaticamente no dia 1 de cada mês |
| RNG-11 | Integridade | Denúncias resolvidas são arquivadas após 90 dias |
| RNG-12 | Segurança | Dados anonimizados para exportação não podem conter informação pessoal identificável |
